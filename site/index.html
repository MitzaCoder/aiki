Start on your own machine

Make room for a little help.

First pilot: v0.1.0-pilot.1 · Linux tested · macOS/WSL experimental · no phone push.

Install, then start

Download and read the small bootstrap before running it. It fetches the versioned GitHub release installer and verifies its SHA-256 checksum.

curl -fL https://aikilabs.dev/install.sh -o install.sh
# Read install.sh before running it.
sh install.sh --version v0.1.0-pilot.1 --no-service
aiki start

You need git; install jj for isolated workers. The pilot installer supplies private Bun and zellij. Checksums detect corruption, not a compromised publisher. Full guide & direct GitHub downloads.

Open your workbench

In another terminal:

aiki open
aiki pair

Open the private pairing URL in the same browser. Then connect a provider, choose a project folder and pick a coordinator model. Keep pairing links private.
