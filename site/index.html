Start on your own machine

Make room for a little help.

Current pilot: v0.1.0-pilot.3 · Linux tested · macOS/WSL experimental · no phone push.

Install, then start

Download and read the small bootstrap before running it. It fetches the versioned GitHub release installer and verifies its SHA-256 checksum.

curl -fL https://kemiri.dev/install.sh -o install.sh
# Read install.sh before running it.
sh install.sh --version v0.1.0-pilot.3 --no-service
kemiri start

You need git; install jj for isolated workers. Linux x64/arm64 and macOS arm64 use a standalone executable, with private Bun as a fallback. The installer also supplies zellij. Checksums detect corruption, not a compromised publisher. Full guide & direct GitHub downloads.

Short install: curl -fsSL https://kemiri.dev/install.sh | sh. The pinned pilot.3 predates the rename: use aiki instead of kemiri until the bridge release.

Open your workbench

In another terminal:

kemiri open
kemiri pair

Open the private pairing URL in the same browser. Then connect a provider, choose a project folder and pick a coordinator model. Keep pairing links private.

Take the view with you.

Download the signed Android APK (Android 12+). Your phone needs your backend reachable over HTTPS; the APK is not a tunnel.

Personal, not sandboxed. Kemiri runs commands with your permissions and provider spending authority. Every paired device has full owner access. This is not a multi-user service. Keep the backend private.
