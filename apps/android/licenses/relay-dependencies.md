# Relay account sign-in dependencies

The app includes Firebase Authentication 25.0.0 (`com.google.firebase:firebase-auth`), AndroidX Credential Manager
1.6.0 (`androidx.credentials:credentials` and `credentials-play-services-auth`), and Google ID 1.2.1
(`com.google.android.libraries.identity.googleid:googleid`). The Firebase Android SDK and AndroidX libraries use
Apache License 2.0. Google ID and the Google Play services bridge also use Google Play services under Google's
SDK terms. See the published artifact POMs and notices for transitive dependencies. No Analytics SDK is added.

- Firebase Android SDK: https://github.com/firebase/firebase-android-sdk/blob/master/LICENSE
- AndroidX: https://cs.android.com/androidx/platform/frameworks/support/+/androidx-main:LICENSE.txt
- Google SDK terms: https://developers.google.com/terms
